# talatThaiR 0.1.0

## Initial release

* Access daily, weekly, and monthly agricultural commodity prices from the NABC API
* Access monthly, quarterly, and yearly production and price indices
* Automatic pagination — no manual page handling required
* Built-in product and category code mappings via `show_*()` helper functions
* Rate limiting (0.3s sleep between pages) to avoid overloading the API
